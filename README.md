## 一、目标与上下文

原项目 `xzrd021/baoma-xiaobai-sanhu-zhishu` 用论坛标题关键词拼接出“宝妈 / 小白 / 散户”概念，传播性强，但存在四个根本问题：

1. **反量化方法论**：拒绝量价、成交额、换手率与资金流，只依赖股吧文本，容易被水军、机器人、反讽和删帖操纵。
2. **脆弱的数据管线**：单次运行同步抓取 308 个论坛页面，海外 CI IP 直接触发 WAF，导致 2026-08-06 后数据永久停滞。
3. **没有定时 CI/CD**：只有离线单测，更新依赖作者在 Windows 上手动双击脚本。
4. **代码与数学失真**：`update_index.py` 膨胀到 4,078 行，用人为收缩算法掩盖数据源失效。

QUANT 2.1 保留用户最容易理解的“宝妈 / 小白 / 散户”三维叙事与 30 个细分板块矩阵，但底层完全改为**可复核的真实市场微观数据**：

- 不抓论坛、不解析标题、不做情绪词表；
- 每一个指数都能追溯到交易所成交额、全市场 5,500+ 只股票的涨跌家数、两融清算数据、涨停/炸板池；
- 数据源缺失时**降权并披露**，绝不伪造“主力/散户”数字；
- 一条命令本地复现，GitHub Actions 零服务器成本自动运行。

## 三、数据源与降级矩阵

| 数据 | 主通道 | 备用通道 | 缺失时的处理 |
|---|---|---|---|
| 指数实时/收盘 | 腾讯财经 `qt.gtimg.cn` | 腾讯 newkline | RSI/BMEI 降权 |
| 全市场成交额/换手 | 腾讯 newkline：上证综指 + 深证综指 | Sina 全市场成交额汇总 | 用指数成交额 Z-Score 代理并标记 |
| 全市场涨跌家数 | Sina `Market_Center` 全量 5,500+ 只 | 上一交易日定稿横截面 | 宽度因子标记缺失，不伪造 50/50 |
| 两融余额/融资买入 | 东财 datacenter `RPTA_RZRQ_LSHJ` | 无 | 两融因子降权，置信度下调 |
| 涨停/炸板/跌停 | 东财 `push2ex` 涨停池 | Sina 横截面按涨跌停价估算 | 标记“估算”，NSI 置信度下调 |
| 主力/小单资金流 | 东财 `push2` fflow（沪+深合并） | 无 | RSI 的 ROFI 因子缺失，权重重分配 |
| 30 板块资金 | 东财行业/概念板块 | Sina 行业+概念资金流（聚合口径） | 标记 `aggregate`，不冒充主力单 |

网络边界全部使用公开 JSON/行情接口，不做浏览器自动化、不绕验证码、不抓论坛。

## 四、核心模型

所有分指数统一映射到 `[0, 100]`，50 为中性中枢。每个因子输出 `score / available / estimated`；子指数在因子缺失时按**剩余权重重新归一化**，并输出 `coverage` 与 `confidence`。

### 1. 散户情绪指数 (Retail Sentiment Index, RSI)

| 权重 | 因子 | 定义 |
|---|---|---|
| 40% | 微观订单流失衡 ROFI | `(小单净流入 - 主力净流入) / 全市场成交额`，经 `tanh` 压缩 |
| 35% | 全市场赚钱效应广度 | `上涨家数 / (上涨 + 下跌)`，来自全量横截面 |
| 25% | 自由流通换手偏离 | 全市场换手率相对近 60 个交易日的 Z-Score |

### 2. 宝妈入场指数 (Out-of-Circle Bubble Euphoria Index, BMEI)

| 权重 | 因子 | 定义 |
|---|---|---|
| 35% | 两融杠杆参与激进度 | `融资买入额 / 该两融数据日的全市场成交额`，60 日分位 |
| 30% | 60 日均线乖离率 | `(上证收盘 - MA60) / MA60 × 100%`，`tanh(±8pp)` 映射 |
| 20% | 换手活跃度 | 60% 换手率 Z-Score + 40% 换手率 ≥10% 的个股占比 |
| 15% | 融资余额动量 | 近 5 个交易日融资余额变化率 |

### 3. 小白跟风博弈指数 (Novice Speculation & Chasing Index, NSI)

| 权重 | 因子 | 定义 |
|---|---|---|
| 40% | 打板封板成功率 | `100 - 炸板率`；炸板率越高，追板吃面风险越大 |
| 35% | 小微盘投机溢价 | 国证2000 相对沪深300 的日收益差，绝对幅度 + 60 日 Z-Score |
| 25% | 涨停情绪梯队 | 70% 涨停家数 + 30% 最高连板高度 |

### 4. 综合情绪指数 (Composite)

`CMSI = 0.40 × RSI + 0.30 × BMEI + 0.30 × NSI`

区间指引：

- **80–100 极度狂热 / 见顶预警**：防守减仓，警惕诱多接盘。
- **65–80 投机升温 / 赚钱效应扩散**：顺势跟踪，严设止盈。
- **45–65 情绪平衡 / 常态博弈**：中性均衡，聚焦主线低吸。
- **25–45 情绪低迷 / 磨底震荡**：耐心潜伏，跟踪企稳。
- **0–25 极度恐慌 / 冰点割肉**：逆向思维，分批布局。

> 置信度低于 65% 时，页面会显示“信号降级”，策略建议前会加“谨慎参考”。

## 五、为什么同时保留 08:30 和 15:30？

A 股 15:00 收盘，但两融清算数据通常要等到收盘后甚至隔夜才更新。只跑 08:30 会丢掉当日收盘横截面；只跑 15:30 又会拿到 T-1 的两融。

因此采用**两段式**：

1. **15:30 收盘定稿**：抓取全市场 5,500+ 只股票横截面、涨停/炸板池、当日成交额与资金流，生成 `data_status=finalized` 的收盘点，写入历史。
2. **08:30 盘前晨报**：复用上一交易日收盘横截面，刷新已经清算完成的两融数据，重算同一交易日的 BMEI，更新历史最后一点（**幂等，不新增重复日期**），并部署为盘前晨报。

这样既满足“每天早上 8:30 看最新一期”的使用习惯，又保证用于计算的横截面和两融数据是完整、可复核的。周末与节假日自动回退到最近一个交易日。

## 六、本地运行

无需第三方 Python 依赖（Python 3.10+ 标准库）：

    python run_pipeline.py --mode auto
    python run_pipeline.py --mode close      # 收盘定稿
    python run_pipeline.py --mode morning    # 盘前晨报
    python -m unittest discover -s tests -v  # 26 个离线单测

查看仪表盘：直接双击 `docs/index.html`，或起一个静态服务器：

    python -m http.server 8000 --directory docs

打开 `http://localhost:8000`。

输出文件：

- `docs/data/latest.json`：最新评级、置信度、覆盖率、原始因子、数据源状态。
- `docs/data/history.json`：60 个交易日滚动序列，字段 `source=actual/backcast/preview`、`estimated`。
- `docs/data.js`：把上述两个 JSON 内联，保证本地双击零 CORS。

## 七、GitHub Actions 与 GitHub Pages

工作流已配置：

- `30 0 * * 1-5`：北京时间 08:30 盘前晨报（`--mode morning`）。
- `30 7 * * 1-5`：北京时间 15:30 收盘定稿（`--mode close`）。
- `workflow_dispatch`：Actions 页面手动触发（`--mode auto`）。
- 先跑单测，再跑管线；单测失败不会污染数据。
- 数据自动提交回 `main`（`[skip ci]`），并上传 `./docs` 到 GitHub Pages。
- `actions/configure-pages@v5` 已开启 `enablement: true`，首次运行会自动创建 Pages 站点，无需手动点 Settings。

首次部署：

    git remote -v
    git push -u origin main

然后进入仓库 **Settings → Pages**，确认 **Source = GitHub Actions**（工作流也会自动尝试开启）。构建完成后访问：

    https://yang-xianfeng.github.io/baoma-xiaobai-sanhu-quant/

## 八、已知边界与合规声明

- **两融 T-1**：15:30 定稿时两融可能仍是 T-1，页面会标注 `T-1 待校准`；08:30 晨报会用最新清算数据重算。
- **历史回溯点**：`history.json` 中 `source=backcast` 的点只用于展示趋势，使用真实价格、成交额、两融与微盘价差，但历史横截面涨跌家数和涨停池无法完整回补，已明确标记 `estimated=true`。
- **板块资金口径**：东财板块资金流可用时为“主力/小单”口径；仅 Sina 可用时为**聚合净流入**，页面显示“聚合口径”，不冒充主力单。
- **不构成投资建议**：本项目是行为金融与市场微观结构的开源研究工具，所有分数与策略文案仅供研究，不构成任何投资建议。
