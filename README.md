# A股散户情绪与市场博弈量化指数 (QUANT 2.0)
### 宝妈·小白·散户指数 专业量化与自动更新版

> 这是一个基于微观订单流、两融杠杆买入激进度、全市场换手偏离度与短线打板套牢率的 A 股专业量化情绪系统。
> 配备 GitHub Actions CI/CD 每日收盘（北京时间 17:30）自动运行与数据更新，静态仪表盘全自动部署至 GitHub Pages。

## ⚡ 为什么彻底重构原版项目（20260806老数据复盘）？

原开源项目 `baoma-xiaobai-sanhu-zhishu` 提出了优秀的社区情绪分群概念（“宝妈”、“小白”、“散户”），但其技术实现与方法学存在致命缺陷，导致其自 2026 年 8 月起彻底停摆：

| 维度 | 原版项目 (`baoma-xiaobai-sanhu-zhishu`) | 本项目 (`QUANT 2.0 量化重构版`) |
|---|---|---|
| **底层核心逻辑** | **反量化教条**：宣称“不使用量价、成交量、换手率”，仅凭 4 个股吧爬虫文本标题做关键词匹配。 | **微观市场结构与行为金融**：以真实资金博弈（主力 vs 散户剪刀差）、全市场换手偏离、两融杠杆为核心。 |
| **数据采集稳定性** | **极度脆弱**：单次运行尝试同步发起 308 个网页论坛爬取，国外 CI/CD 容器 IP 瞬间触发 403 / WAF 封禁。 | **双引擎机构级数据通道**：采用腾讯财经、交易所清算接口与东财公开 OpenAPI，0 验证码、0 爬虫、20秒内极速执行。 |
| **文本与情感分析** | 简单正则词表字典（如“梭哈”、“解套”），无法区分阴阳怪气、反讽、水军刷屏与官方资讯。 | 真实真金白银博弈数据（大单/超大单 vs 小单净流入），无法被论坛水军或水贴刷榜操纵。 |
| **CI/CD 与自动更新** | 仅有离线单元测试工作流，**无定时调度任务**，导致数据永久停留在 2026-08-06。 | **GitHub Actions 全自动流**：每个 A 股交易日 17:30 自动执行计算并部署 GitHub Pages。 |
| **代码设计质量** | 单文件 `update_index.py` 膨胀至 4,078 行，充斥大量掩盖无数据现实的伪“公平席位”计算。 | 模块化设计（`core/` 架构分明，`fetcher`、`quant_engine`、`calendar`），高内聚低耦合，100% 单元测试覆盖。 |

## 📊 四大核心量化指数设计

本系统将所有分指数统一标准化至 $[0, 100]$ 分值体系，以 $50$ 为中性均衡中枢：

### 1. 散户情绪指数 (Retail Sentiment Index - RSI)
* **量化内涵**：衡量全市场散户群体的主流多空倾向与资金跟风强度。
* **合成因子**：
  * **40% 微观订单流失衡 (ROFI)**：$\frac{\text{小单净流入} - \text{主力净流入}}{\text{市场总成交额}}$。散户大额承接而主力出逃时得分极高（追高过热）；散户恐慌割肉出逃时得分极低（冰点探底）。
  * **35% 全市场赚钱效应广度 (MAB)**：$\frac{N_{\text{上涨}}}{N_{\text{上涨}} + N_{\text{下跌}}}$。
  * **25% 自由流通换手率 Z-Score (TO_Z)**：全市场日均换手率相对近 60 日均线的标准差偏离。

### 2. 宝妈入场指数 (Out-of-Circle Bubble Euphoria Index - BMEI)
* **量化内涵**：刻画 A 股“连场外宝妈/小白都开始讨论股票并追入”的**出圈狂热与牛市见顶泡沫风险**。
* **合成因子**：
  * **35% 两融杠杆参与激进度 (MFLR)**：融资买入额占全市场总成交额比例的分位数。
  * **30% 60日均线乖离率 (BIAS60)**：$\frac{P_{\text{上证}} - MA60}{MA60} \times 100\%$。当乖离率突破 +10%~+15% 时触发过热见顶预警。
  * **20% 极端换手尾部占比 (STTR)**：全市场日换手率 > 15% 的个股数量占比。
  * **15% 融资余额动量加速度 (Margin Velocity)**：近 5 日全市场融资余额增长斜率。

### 3. 小白跟风博弈指数 (Novice Speculation & Chasing Index - NSI)
* **量化内涵**：衡量短线高风险打板投机、追高易套牢度与小微盘博弈脆弱性。
* **合成因子**：
  * **40% 打板套牢与封板成功率 (Lock Success Rate)**：$100 - \text{炸板率}$。炸板率极高（如 >50%）说明跟风追板易吃“大面”套牢。
  * **35% 国证2000小微盘投机溢价动量 (MSP)**：国证2000 相对 沪深300 的相对收益率差与成交弹性。
  * **25% 涨停板连板高度热度**：全市场涨停家数与最高连板梯队。

### 4. 全市场综合情绪指数 (Composite Sentiment Index - CMSI)
$$\text{CMSI} = 0.40 \times \text{RSI} + 0.30 \times \text{BMEI} + 0.30 \times \text{NSI}$$

* **量化区间与策略指引**：
  * **$80 - 100$ 极度狂热 / 见顶预警**：出圈狂热与杠杆严重偏离，主力大单出货，警惕诱多接盘，**防守减仓**。
  * **$65 - 80$ 投机升温 / 赚钱效应扩散**：散户买盘充沛，短线题材股弹性放大，**顺势跟踪，严设止盈**。
  * **$45 - 65$ 情绪平衡 / 常态博弈**：多空均衡，板块轮动分化，**中性均衡，聚焦主线**。
  * **$25 - 45$ 情绪低迷 / 磨底震荡**：成交量换手收缩，风险逐步出清，**耐心潜伏，跟踪企稳**。
  * **$0 - 25$ 极度恐慌 / 冰点割肉**：恐慌盘涌现，流动性骤缩，往往对应中长期底部，**逆向思维，分批布局**。

## 🚀 快速上手与本地运行

项目基于 Python 3.10+ 标准库开发，零强制第三方重量级依赖。

### 1. 运行量化更新管线
```bash
python run_pipeline.py
```
程序将自动完成：
1. 校验 A 股官方交易日历（排除周末与法定节假日）；
2. 采集最新行情、订单流、两融与打板炸板数据；
3. 运行多因子行为量化模型计算；
4. 滚动更新 60 个交易日连续历史；
5. 生成 `docs/data/latest.json`、`docs/data/history.json` 及 `docs/data.js`。

### 2. 运行自动化测试
```bash
python -m unittest discover -s tests
```

### 3. 查看仪表盘
直接在浏览器中打开 `docs/index.html`，无需配置任何本地 Web 服务器，即可离线流畅体验交互式仪表盘！

## 🤖 GitHub Actions CI/CD 与 GitHub Pages 部署

项目根目录包含 `.github/workflows/daily_update.yml`：
- **定时触发**：周一至周五北京时间 17:30（UTC 09:30）全自动触发；
- **手动触发**：支持在 GitHub 仓库的 Actions 页面点击 `Run workflow` 一键手动更新；
- **自动提交**：数据更新完成后自动提交回仓库 main 分支（标注 `[skip ci]`）；
- **静态部署**：直接自动发布至 GitHub Pages（`https://<你的用户名>.github.io/<仓库名>/`）。
