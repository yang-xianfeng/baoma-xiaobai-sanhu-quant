方法与数据

四个指数

所有分指数映射到 0–100，50 为中性。因子缺失时按剩余权重重新归一化，并降低置信度。

  • 综合情绪：40% 散户情绪 + 30% 宝妈入场 + 30% 小白跟风。
  • 散户情绪：40% 小单与主力资金剪刀差 + 35% 全市场涨跌家数 + 25% 换手率 Z-Score。
  • 宝妈入场：35% 两融买入激进度 + 30% BIAS60 + 20% 换手尾部热度 + 15% 融资余额动量。
  • 小白跟风：40% 封板成功率 + 35% 国证2000/沪深300 价差 + 25% 涨停梯队。

数据口径

  • 全市场 5,500+ 只股票逐只统计涨跌家数，不用指数成分股代替全市场。
  • 成交额取上证综指 + 深证综指，两融买入占比按该两融数据自身交易日计算。
  • 涨停、炸板、跌停来自东财涨停池；不可用时用横截面涨跌停价估算，并标记。
  • 板块资金优先东财主力/小单口径，其次新浪聚合净流入；聚合口径会在页面标注。

更新节奏

每交易日 08:30 生成盘前晨报：复用上一交易日收盘横截面，刷新隔夜两融清算数据。15:30 收盘后抓取全市场横截面并定稿。周末与节假日回退到最近交易日。

边界

  • 15:30 定稿时两融通常是 T-1，页面会标注，次日 08:30 自动校准。
  • 120 日历史中较早的点为回溯估算，使用真实价格、成交额、两融与微盘价差，图表中标注为回溯段。
  • 本页面是市场行为观察工具，不构成投资建议。
