1. 为什么原版项目（20260806）停滞且失效？

原开源项目 baoma-xiaobai-sanhu-zhishu 存在严重的非专业工程与方法学缺陷：

  • 反量化教条主义：原作者自称“不使用量价、成交量、换手率”，仅靠爬取 4 个股吧论坛标题做关键词匹配。在真实量化金融中，脱离微观订单流与量价的行为学指标极易沦为机器人水军和水贴噪音。
  • 脆弱的 308 个网页同步抓取：每次运行向东财、新浪、同花顺、淘股吧发送 308 次同步爬虫，极易触发海外 CI/CD 容器 IP 封禁与反爬验证码，导致数据在 2026 年 8 月即全盘断流。
  • 缺少日常自动化 CI/CD：GitHub 仓库仅包含离线测试，无任何定时调度和自动部署脚本。

2. QUANT 2.0 机构级量化因子的重构设计

新版系统彻底摒弃脆弱的论坛文本爬虫，基于微观市场结构（Microstructure）与行为金融学经典理论（Baker & Wurgler 2006, Lee et al. 1991），重构四大核心指数：

  • 散户情绪指数 (Retail Sentiment Index, RSI)：权重组合 40% 散户小单净买入 vs 主力大单净流出剪刀差 (Order Flow Imbalance) + 35% 全市场赚钱效应涨跌比 + 25% 自由流通换手率 Z-score 偏离度。
  • 宝妈入场指数 (Out-of-Circle Bubble Euphoria Index)：精准刻画场外非专业群体跟风泡沫。组合 35% 两融杠杆买入激进度 (融资买入额占成交额比) + 30% 60日均线乖离率 (BIAS60) + 20% 极端换手尾部占比 + 15% 融资余额动量加速度。
  • 小白跟风博弈指数 (Novice Speculation & Chasing Index)：度量短线情绪化追涨与套牢风险。组合 40% 打板套牢与炸板率 (Broken Limit Rate) + 35% 国证2000小微盘相对沪深300的投机收益溢价 + 25% 涨停板连板情绪。
  • 综合情绪指数 (Composite Index)：三者加权合成，映射至 0 - 100 标准化区间，中枢为 50。

3. 自动化更新与零成本运行机制

依托 GitHub Actions 自动化 CI/CD：每交易日北京时间 08:30 生成盘前晨报（复用上一交易日收盘横截面并校准隔夜两融清算数据），15:30 收盘后抓取全市场 5,500+ 只股票横截面并定稿。全流程零服务器成本，自动提交并部署至 GitHub Pages。
